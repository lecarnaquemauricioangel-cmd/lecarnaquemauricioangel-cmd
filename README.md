# Angel Constantino Lecarnaque Mauricio

**Frontend & Creative Engineer** con base en Talara, Perú.  
Especializado en interfaces interactivas de alto rendimiento con **React**, gráficos 3D en tiempo real con **Three.js / WebGL** y aplicaciones web impulsadas por **Visión Artificial**.

---

### 🌐 Áreas de Especialización

* **Frontend Moderno:** React 19, TypeScript, Next.js, Tailwind CSS y Vite.
* **3D & Creative Web:** Shaders WebGL, Three.js, partículas interactivas y procesamiento con Web Audio API.
* **Visión Artificial en Cliente:** MediaPipe Tasks (detección facial, landmarks de malla) e inferencia en tiempo real.
* **Integración IoT / Edge:** Comunicación serie en navegador con Web Serial API y pipelines de visión con YOLOv8.
